## 1. 项目概述

系统面向"上课前要同时看时间、看课表、看天气"的重复操作，把三步合并成一条自动链路：课程录入后，在**课前 10 分钟**自动查询天气、生成出行建议文本，再用 **OpenVoice 两级流程**合成指定音色的语音并播放。另提供 FastAPI Web 控制台作为拓展。

**一句话说明实现方式：**

> `Schedule.set_timers()` 用 `threading.Timer` 在课前 10 分钟触发 `weather.gene_advice()`；后者查询天气 → 写 `weather.txt` → 调 `tts()` 生成 `tmp.wav` → `ToneColorConverter` 转换音色得到 `advice.wav` → `play.py` 阻塞播放。

## 4. 一条完整链路示例（以"课前 10 分钟自动播报"为例）

**需求：** FR-04 + FR-09 —— 课前 10 分钟自动完成"查天气 → 生成建议 → 合成 → 播放"。

| 步骤 | 所在文件/函数 | 发生什么 | 证据 |
| --- | --- | --- | --- |
| 1 | `course.py` `Schedule.add_course()` | 课程写入 `OrderedDict`，按 `HH:MM` 升序，持久化到 `data/courses.json` | `data/courses.json` |
| 2 | `course.py` `Schedule.set_timers()` | `reminder_time = course_time - timedelta(minutes=10)`，创建 `threading.Timer` | 终端打印 `[定时] ... 分钟后播报` |
| 3 | `weather.py` `gene_advice()` | 读 `config.yaml`，按 `provider` 选择 mock/qweather | `data/runs.jsonl` 的 `provider` 字段 |
| 4 | `weather.py` `get_weather()` → `fetch_weather_data()` | 字典推导组织双接口，`raise_for_status`，失败返回 `None` | `weather.txt` 降级文案 |
| 5 | `weather.py` `generate_weather_advice()` | 体感三分支 + 雨雪判断 + 分钟级降水，写 `resources/weather.txt` | `weather.txt` 全文 |
| 6 | `tts.py` `tts()` → `_openvoice_tts()` | 第一级 `BaseSpeakerTTS.tts()` 产 `outputs/tmp.wav` | `outputs/tmp.wav` 800.8KB |
| 7 | `tts.py` `_openvoice_tts()` | 第二级 `ToneColorConverter.convert()` 产 `outputs/advice.wav` | `outputs/advice.wav` 18.6s / 800.5KB |
| 8 | `tts.py` `_build_meta()` | 写 `outputs/tts_meta.json` | `engine=openvoice`、`sample_rate=22050`、`reference_segments=3` |
| 9 | `play.py` `play_audio()` | `simpleaudio.wait_done()` 或 `winsound` 阻塞播放 | 扬声器出声 |
| 10 | `weather.py` `_append_run_log()` | 追加 `data/runs.jsonl` | 日志最后一行 |

**对应测试：** TC-03（10 分钟延迟）、TC-04（进入窗口立即触发）、TC-27/TC-28（全链路与降级）、TC-19 ~ TC-23（语音）、TC-24（播放）。

## 8. 难点与解决

| 难点 | 现象 | 解决 |
| --- | --- | --- |
| GitHub / HuggingFace 直连超时 | 权重与源码下载失败 | 源码取 Gitee 镜像，权重取 `hf-mirror.com`，下载脚本带重试 |
| 官方音色提取依赖 whisper | 需联网下载 VAD 模型，离线不可用 | 参考音频等长切 3 段，逐段 `extract_se()` 后平均 |
| 模型加载慢 | 每次播报重复加载 292MB | `_MODEL_CACHE` 进程内缓存，只加载一次 |
| 无 MSVC，`simpleaudio` 装不上 | 导入失败 | `play.py` 主路径保留 simpleaudio，ImportError 降级 `winsound`（同步阻塞） |
| 接口时间带 `+08:00` | `strptime` 解析报错 | 改用 `datetime.fromisoformat()` |
| CPU 推理耗时 | 单次十几秒 | 播报文本控制在两句内；`--demo` 首次加载 + 播放共约 40 秒，满足 45 秒目标；网页「快速合成」走 Piper/SAPI，约 3 秒出声 |
| 断网无法演示 | 天气接口不可用 | 默认 `provider: mock`，字段与真实返回一致；真实 Key 走 qweather |

## 9. 已知限制与后续改进

1. **真实天气 Key 不进提交包**：提交版 `config.yaml` 仍是占位符 `YOUR_QWEATHER_KEY` + `provider: mock`；真实 Key 与专属 API Host 只写在本机 `config.local.yaml`，用 `timer.py --demo --config config.local.yaml` 切真实数据（和风新版 Key 必须走专属 Host，旧 `devapi` 会 403）。

1. **CPU 推理慢于云 TTS**：本机未装 CUDA 版 torch；换 GPU 环境后 `device` 会自动选 `cuda:0`。

1. **超长文本**：690 字可合成但时长 175 秒，不适合播报；Web 已限制 800 字符，实际建议文本 60~120 字。

1. **播放降级**：本机无 MSVC，实际走 `winsound`；`simpleaudio` 路径保留，换机器可自动启用。

1. **跨天课程**：当前按"今天"解释，跨天课程不在范围。

## 10. AI 使用说明（对应评分细则 0.4）

AI 用于：查 OpenVoice 接口用法、生成初始骨架、解释报错、生成 UML 绘图脚本与文档初稿。

**以下判断由本人做出，并写入文档理由：**

- 选择 OpenVoice 而不是通用 TTS：因为需求是"指定音色"，通用 TTS 只能选预置发音人（SRS 2.4）；

- `OrderedDict` 而不是普通 `dict`：插入序不等于时间序，排序逻辑集中在 `add_course`（SDS DD-01）；

- 提前量固定 10 分钟、体感边界固定 8/28：评分细则追问点，行为必须可预期（SDS DD-02）；

- 保留 `tmp.wav`：为了区分"基础合成失败"与"音色转换失败"（SDS DD-03）；

- 切 3 段提取音色：规避 whisper 联网依赖，输入明确可复现（SDS DD-04）；

- 降级必须标注 `engine` 与 `fallback_reason`：不冒充模型输出（SDS DD-07）。

## 12. 二期扩展（第二版）

在原有五模块主链路不变（`advice.wav` 仍由 OpenVoice 生成）的前提下，新增三块能力：

| 扩展 | 实现 | 关键取舍 | 验证 |
| --- | --- | --- | --- |
| 本地实时资讯 | `news.py`：3 个公开 RSS、城市关键词过滤、30 分钟缓存、1~2 条拼进建议；定时播报按 `config.news.enabled` 自动抓取 | 只播标题不播正文，控制时长；全源失败回退缓存且不阻断播报，保证断网仍能演示 | TC-43 ~ TC-50、TC-62、TC-63、TC-67 |
| 多语言多音色 | `voices.py`：4 种语言、16 个音色、5 类引擎；默认 edge 神经音色，试听写独立文件；粤语三档回退（edge → `yue-sapi` → 腾讯云 101019） | `edge-tts` 早期实测连接被重置，后期复测已连通，故把默认引擎从 Piper 换成 edge；粤语优先 `zh-HK-HiuMaanNeural`（零 Key、真粤语），腾讯云作为有 Key 时的商用备份；闽南语因腾讯云不支持（仅中/英/粤）已从系统移除 | TC-51 ~ TC-61、TC-64 ~ TC-66 |
| 双主题界面 | `theme.css` + `data-theme` + `localStorage`；新增 `/news` 页 | 糖果青春为默认、赛博校园保留原深色；首屏内联脚本先应用主题避免闪烁 | TC-33、TC-62 |

**为什么早期说“粤语装完语音包才能说”**：粤语离线音色在 Piper 仓库中不存在，当时 `edge-tts` 的 `speech.platform.bing.com:443` 连接被重置，Baidu 免费 TTS 的 `yue` 参数返回 403，Google 端点超时。后期复测 edge 已连通，最终顺序改为：①edge `zh-HK-HiuMaanNeural`（零 Key、真粤语）→ ②Windows「中文(香港)」语音包（SAPI）→ ③腾讯云 TTS 101019（需 Key 与资源包）→ ④普通话音色显式降级。闽南语经核实腾讯云 TTS 只支持中文/英文/粤语，无可用音色，已从系统移除。
