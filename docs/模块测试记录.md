## MT-01 正常文本（OpenVoice 两级流程）

| 项 | 内容 |
| --- | --- |
| 输入 | 建议文本 60 字：`当前时间为23点52分，14分钟之后有高等数学课。当前体感温度为26摄氏度，气温适宜。未来两小时没有降水，可以不用带伞。`；引擎 `auto`（实际走 OpenVoice） |
| 操作 | `python timer.py --demo`（一条命令，无人工干预） |
| 预期 | 第一级生成 `outputs/tmp.wav`；第二级生成 `outputs/advice.wav`；采样率 22050Hz；`tts_meta.json` 的 `engine=openvoice`、`reference_segments=3`；能听到语音 |
| 实际 | `tmp.wav` 800.8KB；`advice.wav` 800.5KB / 18.6 秒 / 22050Hz；`engine=openvoice`、`device=cpu`、`reference_segments=3`、`fallback_reason=""`；端到端总耗时约 40 秒（含首次加载权重与 18.6 秒播放） |
| 结论 | **通过**。两级产物同时存在，顺序正确；音色转换确实执行（`advice.wav` 与 `tmp.wav` 大小接近但听感不同） |

## MT-02 超长文本（690 字）

| 项 | 内容 |
| --- | --- |
| 输入 | 重复 30 次的课程提醒文本，共 690 个字符；引擎指定 `sapi`（避免 CPU 上长时间占用） |
| 操作 | `python -c "import tts,weather; tts.tts(weather.load_config(), text=..., engine='sapi')"` |
| 预期 | 不崩溃、不产生空文件；输出仍为 22050Hz WAV；时长随文本线性增长 |
| 实际 | 合成成功；采样率 22050Hz；时长 **175.28 秒**；文件 **7548.6KB**；无异常抛出 |
| 结论 | **通过（有边界提示）**。模块能处理超长文本，但 690 字会生成近 3 分钟音频，不适合作为课前播报。Web 端已将单次输入限制为 800 字符；实际建议文本控制在 60~120 字。 |

## MT-03 空 `weather.txt`

| 项 | 内容 |
| --- | --- |
| 输入 | `resources/weather.txt` 内容为空字符串；调用 `tts(config)` 不显式传 `text` |
| 操作 | `pytest tests/test_tts.py::test_empty_text_raises` |
| 预期 | 抛 `ValueError`，提示"待合成文本为空"，不生成静音 `advice.wav` |
| 实际 | 抛出 `ValueError: 待合成文本为空：weather.txt 没有内容，无法生成语音` |
| 结论 | **通过**。空文本被拦截，不会用静音文件冒充播报结果 |

## MT-05 权重缺失（降级 SAPI）

| 项 | 内容 |
| --- | --- |
| 输入 | monkeypatch 让 5 个权重检查全部失败；`engine=auto`；文本 2.58 秒 |
| 操作 | `pytest tests/test_tts.py::test_sapi_fallback_generates_22050_wav` |
| 预期 | 不崩溃；生成 `advice.wav`；采样率 22050Hz；`engine=sapi`；`fallback_reason` 非空 |
| 实际 | 生成 2.58 秒 / 111.1KB / 22050Hz；`engine=sapi`；`fallback_reason="模拟权重缺失"` |
| 结论 | **通过**。降级路径可用且标注真实引擎，不冒充 OpenVoice |
